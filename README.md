# Día de Muertos 2026 · Un altar para Guille y Adrian

Una ofrenda digital para Guille y Adrian, de la Farmacia San Francisco en Guadalajara, Jalisco.
Sigue el camino de pétalos y toca cada objeto para conocer su historia.

A digital ofrenda for Guille and Adrian, who ran Farmacia San Francisco in Guadalajara, Jalisco.
Follow the path of petals and tap each object to hear its story.

The whole altar is one self-contained page, `index.html`, built with Three.js, GSAP and cannon-es.
